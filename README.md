# Aarya Aamish Bhatt - Personal Portfolio

A dynamic, interactive, and responsive single-page portfolio designed for a Quantitative Researcher / Financial Engineer. It showcases professional experience, academic background, quantitative projects, and personal interests (including Formula 1, Pickleball, Chess, and Poker).

## Features
- **Dark "Quant" Aesthetic**: Deep slate background with vibrant cyan and neon green accents.
- **Interactive UI**: 3D tilt effects on project cards, glowing hover states, and smooth scroll animations.
- **Dynamic Hero Section**: Node-particle network animation to reflect algorithmic and mathematical interests.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile viewing.
- **Direct Links**: Integrated routing directly to GitHub and LinkedIn profiles.

## Technologies Used
- HTML5
- CSS3 (Custom animations, Flexbox, CSS Grid)
- Vanilla JavaScript (DOM manipulation, scroll reveals, particle canvas)

## Local Setup
To run this project locally:
1. Create a new folder on your computer.
2. Save the generated code into a file named `index.html` inside that folder.
3. Double-click `index.html` to open it in any modern web browser (Chrome, Safari, Edge, Firefox).

## Customization
- **Images**: Replace the placeholder image URL in the "About" section with a link to your actual professional headshot.
- **Resume**: Update the `href` attribute in the "View Resume" buttons to point to a hosted PDF of your resume.
